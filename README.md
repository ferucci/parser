
# Документация

Обзор архитектуры
Почему MVC?

 - Разделение ответственности: Каждый компонент отвечает за свою зону
 - Масштабируемость: Легко добавлять новые функции
 - Тестируемость: Компоненты можно тестировать изолированно
 - Поддержка: Код легче понимать и модифицировать

# Детальное описание компонентов

1. Модели (Model)
Назначение: Работа с данными и бизнес-логика

ParserModel:
 - fetchPage() - Загрузка HTML с обработкой ошибок
 - parseHTML() - Парсинг и структурирование данных
 - extractScripts()/extractStyles() - Специализированные методы извлечения
Позволяет менять логику парсинга без изменения контроллера

QueueModel:
 - Управление состоянием очереди
 - Отслеживание прогресса обработки
Изоляция логики очереди для возможного использования в других компонентах

FileService:
 - Абстракция для работы с файловой системой
Централизация операций ввода-вывода, легкая замена на базу данных

2. Контроллеры (Controller)
Назначение: Координация между моделями и представлениями

ParserController:
 - processQueue() - Основной цикл обработки
 - processUrl() - Обработка отдельного URL
 - setupEventHandlers() - Настройка коммуникации
Почему EventEmitter: Гибкая система событий для松散 связанных компонентов

3. Представления (View)
Назначение: Отображение данных пользователю

ConsoleView:
 - Форматирование вывода в консоль
 - Цветовые схемы и эмодзи для лучшей читаемости
Возможность добавить Web-интерфейс без изменения логики

4. Поток данных
 - Инициализация: main.js → ParserController
 - Добавление URL: addToQueue() → QueueModel
 - Обработка: processQueue() → processUrl() → ParserModel
 - Парсинг: fetchPage() → parseHTML() → извлечение данных
 - Отображение: События → ConsoleView
 - Сохранение: saveResults() → FileServic


# Project Builder
Назначение:
 - Автоматическое создание локальной копии веб-страницы
 - Скачивание всех внешних ресурсов (CSS, JS)
 - Сохранение структуры проекта для оффлайн-анализа или разработки

# Расположение кода и ответственность
Модели (/src/models/)
- ProjectBuilder.js - Основная бизнес-логика сборки проекта
 - Создание структуры папок
 - Управление файлами проекта
 - Координация процессов

- DownloadService.js - Специализированный сервис загрузки
 - HTTP/HTTPS запросы
 - Обработка ошибок сети
 - Таймауты и повторные попытки

Контроллеры (/src/controllers/)
- ProjectController.js - Координация процессов сборки
 - Взаимодействие между моделями
 - Обработка пользовательского ввода
 - Управление потоком выполнения

Представления (/src/views/)
- ProjectView.js - Отображение прогресса сборки
 - Форматирование вывода
 - Цветовые схемы и эмодзи
 - Статистика и отчеты
